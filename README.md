# Ozon Windows 本地工具 v0.2

浏览器辅助作图测试原型：人工登录和验证，单张任务自动发送、等待并尝试下载，图片本地归档。

## 下载与安装

点击 **Code → Download ZIP**，解压后打开 windows_ozon_tool 文件夹。

1. 安装 Python 3.11 或更新版本。
2. 双击 安装.bat，安装依赖与 Chromium。
3. 双击 启动.bat。
4. 在专用浏览器登录 ChatGPT，新建商品对话，上传原图。
5. 填入商品事实，选择第1张任务，点击自动发送。
6. 下载后人工核对，再继续下一张。

## 状态

已实现：8张图提示词、专用浏览器、下载归档、暂停超时；Ozon 命令行请求预览和显式提交。

尚未实现：图片公开托管、自动提取参数、自动更新库存、GUI连接Ozon发布。

本地校验测试通过，真实 ChatGPT 网页与 Windows 实机尚未联调。页面结构和生成限额可能变化；验证人工处理，不绕过限制。

这是源码测试包，不是免安装EXE。程序不包含密钥、登录数据或商品资料。浏览器登录数据保存在本机 data/browser-profile，不要分享。
