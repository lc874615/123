## 启动与流程

安装 Python 3.11+（含 Tkinter），双击 `windows_ozon_tool/start_edge.bat`。首次会建立本目录虚拟环境并安装依赖。Edge 扩展管理页开启开发人员模式，加载 `edge_extension` 文件夹。在本地“设置”复制配对码到插件，切到专用作图对话，点击“开始 / 继续”。API、COS 和定价来源只在本地配置。

1. **商品制作**：基础货号、共用详情参考、变体表格及各自主图参考；支持点格上传/删除、每列批量填写，产地默认中国。
2. **任务中心**：按组汇总，可展开变体。首变体制作 8 图，其他变体独立主图并复用后 7 张详情。直接采集独立文件，不使用 ZIP。
3. 自动合成 8 秒 MP4，生成覆盖全部变体的一套俄语标题/简介/标签，分别保存到每个变体；未完成素材的变体先保存文案，建立草稿时自动填入。
4. 自动匹配类目与官方属性、计算参考售价、上传图片及视频到 COS，生成各变体 8 图富内容。
5. 整组预览保留参数、共用文案、图片视频、上架进度四页。编辑自动保存，同一参数可跨变体批量修改，图片可点击查看。
6. 点击 **提交/更新整组并自动上架**，依次执行导入、价格同步、所选仓库初始库存设置，并跟进审核和可售状态。受理及创建不等于已上架。

## 四项价格

以工具计算或手动修改后保留的基准售价 P 为准，人民币计价：

| 平台字段 | 规则 | API 字段 |
| --- | --- | --- |
| 最高价格 | 2 × P | price |
| 划线价 | 4 × P | old_price |
| 促销最低限制 | P | min_price |
| 成本 | 对应变体输入的每套成本，不乘件数 | net_price |

P=173.31 时分别为 346.62、693.24、173.31 元及该变体成本。预览显示四项，创建后通过价格接口逐变体同步；回执未成功不会显示整组全部上架。费用与利润以基准价测算。价格同步不代替报名促销或启用自动参加活动。

## 已确认规则

- 改颜色、尺寸、材质或件数只提示素材需更新，由用户手动启动，旧素材先备份；改成本/利润率/价格不重新作图。
- 保留手动售价，重算佣金、运费、利润与利润率；物流不适用或低于目标时提示。
- 共用文案从任一入口编辑均同步全部变体，货号各自独立；主题标签自动规范。
- WEBP 自动转换 JPG，保留原文件，更新图片清单、视频、托管和富内容。
- 新商品每变体初始库存固定 1000；获取店铺全部仓库，不按类型或状态过滤，唯一仓库自动应用；销售后不反复重置库存。
- 参考属性和估算价格自动采用，单元格标红，可直接修改；PDF 停用。
- 本机配对持久保存；重启自动恢复安全查询、已有结果采集、上传及已受理任务跟进，未知生成/导入不自动重发。
- 本地删除/清空进度保留素材和平台商品；执行中先停止并核对，删除备份可恢复。
- 店铺切换隔离仓库、售价配置和回执，暂停旧店铺写入；任务长等待显示原因、时长和上次成功时间。

OGL 边界沿用确认口径：Budget 从 501 克开始，Premium 从 7001 卢布开始，三边之和允许等于上限。参考汇率自动获取俄罗斯央行公布值并显示来源、日期，实际结算以账单为准。
