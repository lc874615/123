# Ozon Edge 扩展＋Windows 本地工具 v0.3

## 安装

1. 下载本仓库ZIP并解压，安装Python 3.11+。
2. 进入 windows_ozon_tool，双击 安装Edge版.bat，再双击 start_edge.bat。
3. Edge地址栏打开 edge://extensions，开启开发人员模式。
4. 点击“加载解压缩的扩展”，选择解压目录中的 edge_extension。
5. 把本地窗口显示的配对码复制到扩展，点击保存。每次重启服务需要重新配对。
6. 使用你当前已登录的ChatGPT，建立商品专用对话并人工上传原图。
7. 在本地窗口填写SKU及真实商品资料，创建8张任务。
8. 在目标ChatGPT标签页点击扩展的“执行下一张”。保持页面打开；保存后检查 data/products 下的图片，在本地确认审核，再执行下一张。

## 边界与验证

扩展只在你点击的ChatGPT标签页注入脚本，不读取Cookie，不另建浏览器登录。只向127.0.0.1本地服务发送任务状态及当前生成图片。服务需配对码、扩展来源和本机Host校验。

新回复仅有一张足够清晰的图片时尝试读取网页可访问的图像资源，可能受CORS或页面变化影响；不保证获取生成平台最大原始分辨率。失败不自动重发，验证和限额由人工处理。

异常任务暂停整个队列，当前版需人工处理后重建新SKU任务；不会自动恢复不确定发送。不要重新发送已经生成的任务。

本地状态与图像校验测试通过，Edge真实ChatGPT页面、MV3后台休眠和Windows实机尚未联调。

当前版未接通图片公开托管、参数提取、俄文文案自动生成、GUI发布或库存更新。publish.py保留独立命令行预览/显式提交入口。Ozon仍需可公开读取的HTTPS图片链接。

旧版Playwright代码仅作历史兼容保留；请按以上Edge版入口启动，无需安装Chromium。

程序不含商品资料或密钥。data目录和配对码仅保存在本机。
