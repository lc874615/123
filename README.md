# Ozon Edge 扩展＋Windows 本地工具 v0.3.1

## 安装

1. 下载本仓库ZIP并解压，安装Python 3.11+。
2. 进入 windows_ozon_tool，双击 安装Edge版.bat，再双击 start_edge.bat。
3. Edge地址栏打开 edge://extensions，开启开发人员模式。
4. 点击“加载解压缩的扩展”，选择解压目录中的 edge_extension。
5. 把本地窗口显示的配对码复制到扩展，点击保存。每次重启服务需要重新配对。
6. 使用你当前已登录的ChatGPT，建立商品专用对话并人工上传原图。
7. 在本地窗口填写SKU及真实商品资料，创建8张任务。
8. 在目标ChatGPT标签页点击扩展的“执行下一张”。保持页面打开；保存后检查 data/products 下的图片，在本地确认审核，再执行下一张。

## 边界与验证

扩展只在你点击的ChatGPT标签页注入脚本，不读取Cookie，不另建浏览器登录。只向127.0.0.1本地服务发送任务状态及当前生成图片。服务需配对码、扩展来源和本机Host校验。

新回复仅有一张足够清晰的图片时尝试读取网页可访问的图像资源，可能受CORS或页面变化影响；不保证获取生成平台最大原始分辨率。失败不自动重发，验证和限额由人工处理。

异常任务暂停整个队列，当前版需人工处理后重建新SKU任务；不会自动恢复不确定发送。不要重新发送已经生成的任务。

本地状态与图像校验测试通过，Edge真实ChatGPT页面、MV3后台休眠和Windows实机尚未联调。

当前版未接通图片公开托管、参数提取、俄文文案自动生成、GUI发布或库存更新。publish.py保留独立命令行预览/显式提交入口。Ozon仍需可公开读取的HTTPS图片链接。

旧版Playwright代码仅作历史兼容保留；请按以上Edge版入口启动，无需安装Chromium。

程序不含商品资料或密钥。data目录和配对码仅保存在本机。

## v0.3.1 原图入口
本地窗口新增“选择商品原图（可多选）”，支持最多8张PNG/JPG/WEBP，每张不超过3MB。创建任务时复制至本机商品目录，扩展执行任务时尝试附加到ChatGPT输入框；当前每张任务均附加所选参考图。若网页上传控件变化，停止并提示，不自动重发。原图上传完成状态的识别仍需真实Edge页面验证。

更新时先关闭旧本地服务；使用新代码启动，并在 edge://extensions 点击扩展“重新加载”，刷新ChatGPT标签后重新配对。旧任务没有原图记录，请用新SKU建立带原图任务；不要删除已有图片。

## v0.3.2 输入框与异常恢复
支持多种可见ChatGPT输入框，在领取任务前检查页面；未识别输入框不会再领取新任务。旧异常任务：先在扩展暂停并刷新ChatGPT，确认没有发送，再在本地选中该任务，点击“所选异常任务未发送，重新排队”。更新需要替换local_bridge.py和edge_extension整个目录，在Edge重新加载扩展并刷新ChatGPT页面，重新配对。不要删除data。真实页面变化仍可能需要更新选择器。

## v0.4 自动8图＋8秒视频
重新运行安装Edge版.bat以安装视频依赖，重新加载edge_extension并刷新ChatGPT页面、重新配对。先在目标商品对话点击扩展“绑定此标签并开启自动批次”，以后在本地创建商品即自动处理。扩展最多约30秒轮询一次。保持Edge和本地工具运行，勿在绑定对话另发消息。

每张图保存后自动继续，不再逐张确认。全部8张保存成功后本地合成1080×1440、30fps、H.264 MP4无声视频，每图1秒，共240帧/8秒。原图存于data/products/SKU/images，视频存于data/products/SKU/video/product_8s.mp4。该视频为图片轮播，不是AI商品动态视频。最终素材仍需人工审核再用于上架；本版本不自动发布。

验证或限额、网页结构变化会停止批次；先处理网页再人工恢复异常任务。旧版review/needs_attention任务会阻塞队列，需先处理。当前MV3长任务和真实ChatGPT页面仍待实机测试；后台休眠导致状态丢失时不自动重发。视频失败保留全部图片。

## v0.4.1 自动原图上传修复
优先选择image类型控件，单文件控件逐张上传，附件预览出现且上传进度结束才发送。未能确认上传就暂停，不要求手动上传作为正常流程。实际网页附件DOM变化仍需实机验证。新增“取消所选商品剩余任务（保留文件）”，先停止扩展批次后取消旧异常商品即可解除队列阻塞。更新需替换local_bridge.py及整个edge_extension目录，重新加载扩展、刷新ChatGPT并重新配对；保留data。

## v0.5 一次请求8张独立图
新商品创建一个整套任务，一次发送8图要求；收到8张独立图片后按网页DOM显示顺序保存，第一张01_main为主图，生成image_manifest.json及8秒轮播视频。网页不保证一次输出8个文件，若只返回单图/拼图或数量不符，等待20分钟后暂停，不把拼图切割冒充独立原图。图片识别支持新图片卡片位于回复文本外的页面布局；仍需真实页面验证。DOM顺序可能与模型承诺顺序不同，主图最终需人工审核。旧任务不自动迁移，先停止并取消旧商品剩余任务再建立新任务。

## v0.7 简洁任务表及创建后联动
任务列表改为SKU、图片进度、简短状态；可逐条删除选中任务记录，不删除素材，正在执行的任务必须先停止。新商品点击创建后自动接续8图、视频、上架草稿与俄文文案，需事先绑定扩展并开启自动批次。类目、定价、托管和实际提交尚未联通，不会自动上架。已有任务复制文案需审核，默认无品牌不应列为缺失项。异常、验证及限额仍暂停。

## v0.8 变体参数表
基础货号填写一次，各列为变体1、变体2…；点击增加变体新增列，货号生成 基础货号(1)、基础货号(2)…，与草稿offer_id一致。支持逐格编辑、当前值填充整行、从Excel粘贴TSV矩阵。每列独立选参考图。参数包含名称用途、颜色、规格、套装数量、材质、配件材质、商品和包装尺寸、净重与包装总重、每套成本、利润率、库存、产地、组装方式及其他事实。单位分别为cm、g、人民币；未知留空不猜测。库存默认1000，利润率表格默认25%可修改。

点击创建全部变体，生成相互独立的8图、视频、文案及草稿；同基础货号保留为分组信息。Ozon合并为同一买家商品页仍取决于类目、品牌、型号及变体属性，并非仅凭货号后缀就会自动合并。本版仍未接通实际发布、类目匹配、定价和托管。内部JSON为兼容旧数据保留sku字段，界面显示为货号。

批量粘贴从当前聚焦格起，按参数行顺序填入，不含表头；可粘贴一列或多列。建议每个变体使用独立ChatGPT商品对话；当前仍使用绑定对话串行处理，需留意历史外观污染。更新保留data。

## v0.9 商品组共享素材与文案
同组随机型号在创建时生成一次并持久化。变体1生成8图，后续变体只生成主图并复制变体1的7张详情图，每个变体仍有8图及视频。共享详情图提示词汇总全部变体差异，不将单一规格当成全组。

同组文案根据全部变体生成一次，后续变体引用相同文案并保留各自货号。类目推荐使用本机环境变量OZON_CLIENT_ID/OZON_API_KEY访问实时类目树，当前为俄文关键词初筛，需卖家确认；缺凭据会记录失败提示。点击“确认或修改所选商品类目”可选候选或手动填ID。改类目仍需重取属性校验。本版没有实际提交发布。

同组变体共用详情时必须审核颜色及尺寸是否兼容；复制图片不代表平台商品页自动合并。共享参数、真实网页与类目推荐仍需实机联调。
