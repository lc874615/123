# v0.29 整组编辑、店铺仓库库存与提交上架

整组预览每列一个变体，按官方类目API显示中文/俄文属性，支持逐格编辑、选中变体同一参数批量填写（相同值或每行不同值）。改类目会重新读取属性与字典，保留可复用的已填值；无法确认的值提示重新选择。参数修改后自动重算售价。

仓库通过当前店铺 `/v2/warehouse/list` 实时获取，只提供可用rFBS仓库，不自动选择第一个。可逐变体设置，也可批量应用；库存对应所选仓库，提交时重新核对店铺、仓库状态及数量。

“提交/更新整组并自动上架”会真实导入/更新商品，随后向所选仓库写入库存，并查询审核与可售状态。提交前需补全官方必填、税率、店铺币种、售价、图片和视频。库存0不视为可售。API受理不等于审核通过；进度页区分导入、库存、审核与可售。

请求意图与回执保存在本地，重启后继续跟踪。写入响应不明时先查询，不能确认则暂停并提供明确恢复操作，避免重复写入。仅更新文案/售价不会把已售库存重置；明确编辑库存或仓库才产生新的库存设置。取消跟踪不会撤销平台已有商品或库存。

更新请保留 `data` 和 `.venv`，从 `start_edge.bat` 启动；无需重新生成现有素材。本版150项Python、18项JavaScript测试通过；Windows界面及真实店铺写入仍需实机验证，开发过程中没有提交用户商品。

以下为历史版本记录。

# v0.28 视频链接与必填属性提交预览

## 已有本地MP4，如何补视频链接

关闭旧本地服务，更新程序文件，保留原有`data`、`.venv`，运行`start_edge.bat`。本版无新增安装依赖。

已有COS已保存配置会继续使用。图片显示8/8后，后台读取各货号的`video/product_8s.mp4`，检查MP4容器、H.264标记及8秒时长，上传COS并匿名读取核对完整文件SHA-256，回填草稿的`video.https_url`。不重新作图、不改变现有视频内容；任务列表显示“视频✓”后表示链接已回填。

视频保存至原目录下`ozon-images/videos/视频SHA256.mp4`，沿用原`ozon-images/*`写入权限。不要重新开通云服务。上传/校验仍可能产生请求及下行流量费用，沿用COS计费。

若本地MP4缺失、过短、过长、未检测到H.264或图片比视频新，状态会列明原因。选中变体后可点击“重新合成所选变体8秒视频并自动托管”，使用已有8张图片重新合成；无需重新生成图片。

## 完善必填属性

1. 选中变体，点击“上架草稿 / 必填属性 / 整组提交预览”。类目确认后，后台会自动读取官方属性；也可点击“读取 / 刷新官方必填属性”。
2. 若提示没有API连接，点窗口内“连接Ozon API”。所需为卖家后台Client-Id和Api-Key，与COS密钥不同。Windows可选择加密记住，后续重启自动恢复；不记住时仅本次运行生效。
3. 属性名称使用官方中文和俄文，支持关键词搜索及“只看缺失的必填项”。双击修改。字典字段必须选择官方选项，支持中文选项分页、关键词搜索；非字典字段可直接填写文本或数值。
4. 工具会按真实已填参数建议品牌、型号、产地、颜色、主体材质、内衬材质、件数及部分尺寸；字典必须精确匹配才自动填ID。未知承重、证书等不猜测。主体和内衬分别处理。品牌仍固定无品牌，型号沿用本商品组自动生成值。
5. 标题、简介、标签沿用全组共用文案。包装长宽高从参数中的包装字段转换为API毫米，重量使用包装总重量克；不得把商品展开尺寸填成包装尺寸。

## 确认与整组预览

选择实际适用增值税率，并勾选已确认店铺币种为人民币CNY。本工具不自动认定免税。**税率是平台申报字段，不会因此自动改变已确认的定价公式；实际税费成本须核对是否已反映在成本或售价中。**

可确认当前变体，也可点击“查看并确认整组属性、税率和币种”，先查看各货号完整属性，再一并确认。任何变体缺少必填项，整组确认都会停止；查看后参数/属性改变也须重新核对。同组各变体可有不同官方颜色/规格值，共用文案保持一致。

在“查看 / 确认售价”中确认实际售价后，点击“校验并导出整组上架预览（不提交）”：

- 未通过：输出`listing_preview/review_report.json`，按货号列出缺项；旧的成功载荷不会继续作为本次结果。
- 通过：另输出`listing_preview/ozon_import_preview.json`，包含各变体货号、CNY售价、税率、类目、官方属性、8张图和8秒视频。
- 视频按Ozon`complex_attributes`的100001组及21841链接/21837名称字段组织；不把MP4混入图片数组。
- 类目、属性、售价、图片/视频变化、缓存过期或任务取消后，旧预览不可继续直接使用，须重新导出。字段8229不再作为固定必填项，根字段type_id按官方接口优先使用。
- 这是本地提交前检查，**没有提交商品、设置仓库或更新库存**。平台实际抓取、属性条件校验、变体合并及审核结果仍需后续实际导入确认。

属性接口使用`/v1/description-category/attribute`、`/attribute/values`及`/attribute/values/search`，均只读取元数据/字典。网络请求不持有任务写锁，返回结果只合并到仍匹配的类目与资料，保留同时进行的文案、定价和媒体更新。
