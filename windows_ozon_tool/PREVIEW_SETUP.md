# 整组预览与上架 · v1.0.3

任务中心选中商品组打开预览，四页为参数、共用文案、图片视频、上架进度。

参数来自当前类目 API，每列一个变体，可双击单格及勾选后批量修改同一参数。支持中文/俄文搜索；换类目重新读取并回填兼容的已知内容，不匹配的字段提示补齐。

自动使用净重、包装尺寸和重量、每套件数、产地、颜色、材质及共用文案等数据。货号各自独立；系列名称默认 1、组内型号统一；原厂包装数量默认 1。按各变体的 8 图生成富内容，自动填视频链接和标题。参考值标红，可手动改，PDF 停用。

标题/简介/标签从参数表或文案页修改都同步全组并分别保存。无草稿的变体先保存共享文案，后续自动填入。图片点击可放大，主图各自独立、后 7 图共用。

最高价=基准价×2，划线价=基准价×4，促销最低限制=基准价，成本=输入的每套成本。基准价手动修改后保留，重新计算费用与利润。

读取当前店铺全部仓库，不按类型/状态过滤；名称旁显示原始类型和状态，唯一时自动应用全组。新商品初始库存固定 1000，销售后不反复重置。

提交先执行 /v3/product/import，确认创建后通过 /v1/product/import/prices 同步四项价格，再继续库存和审核跟进。成本字段 net_price。错误回填到变体，未完成不会显示全部成功。导入受理、创建、价格、库存、审核和可售分别跟踪。

回执持久保存，重启继续安全查询；未知导入不重复提交。长时间无进展显示等待时长与上次成功时间。“清空本组进度”只归档本地跟进，保留素材和平台商品；导出、诊断、刷新和异常恢复在“更多”。
