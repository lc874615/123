# Ozon Windows 浏览器辅助作图工作台（原型）

需要 Windows 10/11、Python 3.11+。双击“安装.bat”，成功后双击“启动.bat”。

1. 选择原始商品参考图，打开专用浏览器。
2. 人工登录 ChatGPT；每个商品建立独立对话，人工上传参考图。
3. 选择当前图片任务，点击自动发送。等待生成及下载；验证或异常时人工处理。
4. 工具尝试点击新回复的下载按钮，捕获下载并保存至 data/products/SKU/images/任务名。
5. 检查产品外观、尺寸和俄文；确认下载结束后再切换下一张。

人工验证后继续使用；不自动处理验证码、不绕过网站限制。订阅内生成次数仍受 ChatGPT 限额影响。页面结构变化可能需要更新选择器。

专用浏览器的登录数据保存在 data/browser-profile，只用于本机；不要分享此目录。安装包不含 Ozon 密钥或登录凭据。

当前实现：商品资料保存、8张图提示词、可见浏览器、原图下载事件归档、图片文件头校验、下载记录。
已新增：单张自动发送/等待/下载，暂停与超时、异常不重发，publish.py 上架请求预览及显式提交。
仍未实现：多模态参数自动提取、图片公开托管、批量无人值守、导入后库存自动写入。自动发送和下载选择器尚未在真实ChatGPT网页验证。Python 核心源文件已经语法检查，Windows GUI 和真实 ChatGPT 登录/下载未经实机联调。

本地文件无法直接被 Ozon 抓取，上架仍需要公开可读的图片地址。不要把本机路径填入 Ozon images 字段。

发布命令：`.venv\Scripts\python.exe publish.py 商品请求.json` 仅预览；加入 `--submit` 才提交。先在环境配置 OZON_CLIENT_ID 和 OZON_API_KEY。网络失败留有 .submitting 标记，先在卖家后台核对再处理，禁止直接重复提交。
