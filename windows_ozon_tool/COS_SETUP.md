# 腾讯云COS首次配置

本版接入腾讯云COS。程序只上传8张生成原图，生成固定HTTPS链接并回填本地草稿；不会创建存储桶、购买资源包、开启CDN/全球加速或提交商品。

## 费用

腾讯云当前新个人用户权益为50GB标准存储、180天；新企业用户标准存储额度不同。免费存储包**不抵扣请求及外网下行流量**。上传后的匿名校验和Ozon抓图会产生请求/下载。实际权益和费用以账号控制台为准，不能保证免费。

## 一次配置，后续自动

1. 在[腾讯云COS控制台](https://console.cloud.tencent.com/cos/bucket)创建或选择专门用于公开商品图片的存储桶。使用普通标准存储，记录**地域代码**（如`ap-hongkong`）与**完整Bucket名称**（如`商品桶名-APPID`，实际名称须符合COS命名规范）。地域必须与这个桶实际地域一致。
2. 该桶设为**公有读、私有写**；防盗链需允许不带Referer的请求，以便Ozon服务端匿名抓图。程序不会替你修改桶权限。
3. 在[腾讯云CAM](https://console.cloud.tencent.com/cam/capi)取得有该桶`ozon-images/*`目录`cos:PutObject`权限的子账号SecretId/SecretKey。程序不需要删桶、删文件或修改ACL的权限。
4. 启动本地工具，打开“腾讯云COS托管设置 / 自动生成链接”，填写Region、Bucket、SecretId、SecretKey。密钥只在本地填写。Windows勾选“加密记住”后使用当前系统用户的DPAPI保护，重启后继续自动执行；不勾选时密钥仅保留于本次运行。移动到另一Windows用户后须重新填写密钥。
5. 点击“保存并自动上传已有及后续生成图片”。只处理当前任务列表内未取消的商品，删除任务保留的旧素材不会继续上传。需先有完整8图清单与售价；不齐备时等待，齐备后继续。

本地可以使用环境变量预填：`COS_REGION`、`COS_BUCKET`、`COS_SECRET_ID`、`COS_SECRET_KEY`；首次仍须在界面保存并启用上传。

## 自动流程与文件位置

创建 → 生成图片/8秒视频及共用文案 → 官方类目推荐及同组同步 → 每个变体估算售价 → 自动上传8张生成图片 → 匿名下载原图核对SHA-256 → 逐张回填 `data/products/货号/listing_bundle.json` 中的 `images[].https_url`。

- 01始终是该变体自己的主图；02—08沿用首变体的共用详情。按文件内容去重，3个变体通常上传3张主图＋7张详情，共10个不同文件。
- 不上传参考图、文案、原始参数、视频或配对码。若历史素材误混参考图，检测后暂停该商品并给出原因。
- 不压缩、不改图，不生成会过期的签名下载URL。COS公开对象路径为`ozon-images/图片SHA256.扩展名`。
- 每张链接匿名读取校验后才回填；断网保留已完成进度，指数退避重试。已验证缓存24小时内复用，过期后会重新读取校验，因此也会产生下载流量。
- 重新采集改变图片后，变化图片的旧链接标记待补齐；未变化图片继续复用。不会删除远端旧对象；如需释放存储，可自行在COS控制台清理不再上架的图片。
- 界面可暂停/恢复托管，显示每个变体链接进度。只有8个链接均有效回填才移除图片托管阻塞，类目、文案、售价等其他审核条件保留。

COS部分新建桶的默认域名会让浏览器直接下载图片，而非页面内预览，这是默认域名行为；工具按匿名HTTP获取的图片内容校验，不依赖浏览器预览。实际Ozon抓取结果仍需上架时核验。

## 常见状态

- **等待类目/售价**：先在售价窗口查看类目、佣金匹配或参数缺失原因；补齐后自动继续。
- **403**：检查Region/Bucket、SecretId/SecretKey及PutObject权限；若发生在匿名读取阶段，检查公有读、防盗链空Referer及账号欠费情况。
- **409**：同名内容文件可能已由上次上传成功；程序会直接校验并复用，不覆盖其他对象。
- **网络失败**：自动保留已完成进度、延迟重试；也可点“恢复 / 重试未完成图片”。
- **远端与原图不一致**：不回填该链接，保留本地文件；检查对象路径和云端文件。

本次开发环境未连接你的COS账户，不含你的密钥，未实际上传商品图片。首次配置完成后需检查8/8链接并实测Ozon抓取。
